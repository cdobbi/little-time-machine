# Little Time Machine

Little Time Machine helps BYU Pathway religion teachers and students understand class times across time zones and daylight saving time changes.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
